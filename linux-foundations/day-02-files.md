# Day 2: Files and Directories

## Commands practiced

- `pwd`
- `ls`
- `mkdir`
- `touch`
- `cp`
- `mv`
- `rm`
- `rmdir`

## Practice

Run these from the project root:

```bash
pwd
ls
mkdir day-02-lab
touch day-02-lab/example.txt
cp day-02-lab/example.txt day-02-lab/copy.txt
mv day-02-lab/copy.txt day-02-lab/renamed.txt
ls day-02-lab
rm day-02-lab/example.txt
rm day-02-lab/renamed.txt
rmdir day-02-lab
```

## Notes

Today I practiced creating files and directories, copying files, renaming files, and cleaning up empty directories.
